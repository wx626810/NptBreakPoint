# 无痕断点 · 人工操作手册（R3）

> **给谁用**：操作人员 / 调试人员，不需要懂内核原理，按步骤操作即可。
> **干什么**：在 Windows 上开启"无痕断点"——下断点后，目标进程内存里**永远不会出现 0xCC 断点字节**，调试器/反作弊扫描内存看到的永远是原始指令；断点命中、单步、继续全部照常工作。
> **环境**：AMD 处理器（需 SVM 虚拟化支持），Windows 10/11 x64，管理员权限。

---

## 0. 前置条件（一次性准备）

| 项 | 要求 |
|---|---|
| 处理器 | AMD，支持 SVM（AMD-V）|
| 系统 | Windows 10/11 x64，已开启测试签名 |
| 文件 | `output\NpHv.sys`（驱动）、`output\NpHvCtl.exe`（控制工具）|
| 权限 | 所有命令以**管理员**身份运行 |

**开启测试签名**（首次部署前执行一次，需重启）：
```bat
bcdedit /set testsigning on
:: 重启后桌面右下角出现"测试模式"水印即成功
```

**部署驱动**：
```bat
copy /Y output\NpHv.sys C:\Windows\System32\drivers\NpHv.sys
sc create NpHv type= kernel binPath= C:\Windows\System32\drivers\NpHv.sys
```

---

## 1. 第一步：启动 Hypervisor

```bat
sc start NpHv
NpHvCtl status
```

**必须看到**：
```text
hypervisor    : yes        ← 关键！否则后面全部命令都会失败
processors    : 8
```

如果 `hypervisor: no` 或命令报"打开设备失败"，见末尾"常见问题"。

---

## 2. 核心操作：安装无痕断点

### 2.1 三种断点模式（`bp` 命令）

```bat
NpHvCtl bp NtQuerySystemInformation                :: ① 自动单步（推荐）
NpHvCtl bp 0xfffff80012345678 halt                 :: ② 暂停模式
NpHvCtl bp NtCreateProcessEx halt oneshot          :: ③ 暂停 + 单次
```

| 模式 | 写法 | 行为 |
|------|------|------|
| 自动单步（默认）| 不带标志 | 命中→记录现场→**自动单步执行原指令**→重新布点，程序不感知停顿 |
| 暂停（HALT）| `halt` | 命中后**钉住该线程**，等你用 `bpcont` 放行——适合分析现场 |
| 单次（ONESHOT）| `oneshot` | 命中一次自动解除，适合"只抓第一次" |

> 地址写法：函数名（`NtQuerySystemInformation`）或内核地址（`0xfffff800...`）都行。
> 断点目标页的**取指视图**才含断点逻辑；**读内存视图始终是原始字节**——这就是"无痕"。

### 2.2 查看断点与命中（`bplist`）

```bat
NpHvCtl bplist
```
```text
breakpoints: 1 active (total 1)
  #1  STEP addr=0xFFFFF800...  hit=42  cpu=2  cr3=0x...
```
`hit` 列增长 = 断点正在生效。

### 2.3 继续 / 删除

```bat
NpHvCtl bpcont 2          :: 继续 #2（暂停模式）
NpHvCtl bpcont all        :: 继续所有暂停的断点
NpHvCtl bpdel 1           :: 删除 #1 断点
```

## 3. 推荐场景：X64DBG 全流程无痕调试

**这套流程下你不需要手动下 bp**——打开两个开关，然后**在 X64DBG 里正常操作**（F2 下断点、命中暂停、F8 单步、看内存），底层全部自动转无痕。

### 3.1 两个开关

```bat
NpHvCtl dbg hide on       :: ① 调试链路隐藏（关键开关）
NpHvCtl drprobe on        :: ② 硬件断点接管（只用软件断点可跳过）
```

### 3.2 然后纯 X64DBG 操作

```text
1. X64DBG → 文件 → 附加 → 选择目标进程
   （自动识别，无需手动 protect）
2. 目标代码处按 F2 下断点
   → 驱动自动拦截"写 0xCC"，转成 NPT 无痕断点，内存不落字节
3. 运行到断点 → X64DBG 正常暂停（显示命中位置）
4. F8 单步 / F9 继续 / 查看堆栈 / dump 内存，全部正常
5. 反作弊视角验证（见 §6）
```

### 3.3 会话结束

```bat
NpHvCtl dbg hide off
NpHvCtl drprobe off
```

## 4. 硬件断点接管（可选，`drprobe`）

X64DBG 的 F2 **硬件断点**（写 DR0-3/DR7）默认会真实写入寄存器，反作弊能扫到。
`drprobe on` 后：调试器写 DR → 驱动拦截记入"假 DR"，读 DR → 回显假值。

```bat
NpHvCtl drprobe on        :: 开启接管
:: 在 X64DBG 设硬件断点（F2 切到硬件类型）
NpHvCtl drstate           :: 查看被接管的断点（地址+类型）
```
```text
drprobe: enabled
  pending hardware breakpoints: 1
    [0] addr=0x00007FF6A1C01000  type=execute
```

> 只调软件断点时**不需要**开 drprobe，保持默认关（零开销）。

---

## 5. 数据监视（可选，`mon`）

想监视"谁在读写某块内存"（不占 DR 寄存器）：

```bat
NpHvCtl mon 0xfffff80012345678 rw     :: 读写都监视
NpHvCtl mon NtQuerySystemInformation w
NpHvCtl mondel 1                      :: 删除监视
```

> AMD 注意：读监视会连取指一起拦（AMD NPT 无 execute-only），监视函数代码页时慎用。

---

## 6. 验证"真的无痕"

目标进程运行中，从**另一视角**检查（例如用 Cheat Engine / 任务管理器之外的工具扫内存）：

| 检查项 | 期望结果 |
|---|---|
| 断点地址处内存字节 | **原始指令**（不是 0xCC）|
| DebugPort / 调试对象 | 查不到（DebugPort=0）|
| DR0-3/DR7 | 全 0 或假值（若开了 drprobe）|
| 内存扫描软件 | 扫不到任何 0xCC 断点痕迹 |

---

## 7. 关闭与卸载

```bat
NpHvCtl unload            :: 卸载 Hypervisor（含排空，等待返回）
sc stop NpHv              :: 停止驱动服务
sc delete NpHv            :: 删除服务（彻底移除时）
```

## 8. 常见问题排查

| 现象 | 处理 |
|---|---|
| `sc start NpHv` 失败 | ① 测试签名未开启（重看 §0）② 驱动路径/文件名不对 ③ AMD SVM 被 BIOS 禁用（进 BIOS 开 SVM）|
| `status` 显示 `hypervisor: no` | CPU 不支持 SVM / 已被其他 hypervisor 占用（Hyper-V 开着时先关：`bcdedit /set hypervisorlaunchtype off` 重启）|
| 命令报 `err=1` / `err=87` | 驱动版本与 NpHvCtl 版本不匹配 → **两个文件都从 `output\` 一起拷贝**，重装驱动 |
| 下断点报 `0xC00000BB` | 虚拟化没起来（回到 §1）|
| 断点命中但 `hit` 不涨 | 断点地址没被执行到（目标函数没被调用）|
| 蓝屏（0xA / 0x50） | 用旧版驱动 → 换最新 `output\NpHv.sys`；测试机建议先关 Hyper-V |
| X64DBG 附加不上 | `dbg hide on` 已开启时若仍未自动保护，手动 `NpHvCtl dbg protect <PID>` |

## 速查卡（复制即用）

```bat
:: 启动
sc start NpHv && NpHvCtl status

:: 纯内核断点（不挂调试器）
NpHvCtl bp NtQuerySystemInformation
NpHvCtl bplist
NpHvCtl bpdel 1

:: X64DBG 无痕调试
NpHvCtl dbg hide on && NpHvCtl drprobe on
:: → X64DBG 附加、F2、命中、单步、F9……
NpHvCtl bplist && NpHvCtl drstate
NpHvCtl dbg hide off && NpHvCtl drprobe off

:: 关闭
NpHvCtl unload && sc stop NpHv
```
