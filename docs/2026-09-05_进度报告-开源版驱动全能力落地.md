# 2026-09-05 进度报告：NptHook 开源版驱动 — 全能力落地

> 本报告覆盖项目启动至今的驱动层功能演进与当前状态。
> 本版本为去除授权验证 / 生产配置 / 商业化组件后的开源版本。

## 一、驱动核心能力（全部完成）

### 1. NPT 无痕 Hook（三态状态机）

- 每核独立 NPT + 恒等映射，影子页 0（干净 + NX）/ 影子页 1（入口 0xCC）双视图
- 状态 A → B → C 转换 + 影子页复位线程双保险
- 页内任意地址断点（NPF 处理器动态识别入口 vs 页内）
- 跳板模板完整拷贝（全 GPR/XMM 保存 + 回调 + 序言重放 + 跳回）

### 2. NPT 无痕断点 / 监视（NpBreakPoint）

- 页级共享影子（BREAKPOINT_PAGE + g_BpPageListHead）：同页多断点共享一次切换
- 自动单步（RFLAGS.TF + 拦截 #DB）、HALT（RIP 回退 + NX 钉线程 + VMMCALL 继续）、ONESHOT
- 删除三层判据：写回原字节 / 非暂停期写 0xCC / continue 无 step-over = zombie reap
- NPT 监视：R/W 权限陷阱 + 单步重收紧，不占 DR0-3
- 无痕读写：PID → DTB → 遍历四级页表（含 2MB/1GB 大页）→ 物理直读

### 3. DR 硬件断点虚拟化（drprobe）

- SVM 拦截 DR0-3/DR6/DR7 读写，真 DR 永远干净
- 调试器写 DR → HV 记录假 DR → NPT 承担实际断点
- 读回显假 DR（调试器看到它写的值）
- REX 0F 21/23 解析（REX.B 扩展 rm），模拟后 Rip=NRip

### 4. X64DBG 调试器适配（NpDebugHide）

- 附加自动保护：NtDebugActiveProcess 拦截 → 注册白名单 + 自动 drprobe
- F2 软件断点：NtWriteVirtualMemory 拦截 → NPT 无痕断点（0xCC 永不落内存）
- F2 硬件断点：NtSetContextThread 写 DR → 自动转 NPT
- 读内存/堆栈：NtReadVirtualMemory → 物理直读
- DebugPort/DebugObjectHandle/DebugFlags 伪造（NtQueryInformationProcess）
- white/black 双模式（白名单 = 仅调试目标隐藏 / 黑名单 = 除注册 PID 外全隐藏）

### 5. 自隐藏 / 反检测

- 模块 DKOM 摘链（PsLoadedModuleList 双向链表）
- QSI 全类过滤（11/59/70）：NtQuerySystemInformation 按类过滤驱动条目
- LSTAR 分流：MSR LSTAR 读写 NPT 影子页 + QSI 交叉保护
- 无设备化：随机设备名 + hypercall GET_DEVICE_NAME + NPT_NO_DEVICE
- 反检测：CPUID 叶子隐身、MSR（EFER/VM_CR/VM_HSAVE_PA）伪装

### 6. 进程 / 数据 / SSDT 层

- 进程隐藏（prochide）：摘链 + QSI 过滤藏调试器（反作弊对抗核心）
- 进程监视（watch）：创建/退出通知（legacy callback 绕过签名门槛）
- 虚拟 Hook（VHook）：SSDT 级函数虚拟化
- 数据补丁（DataPatch）：内核数据只读影子（写拦截 + 假值回显）
- SSDT 三级定位：Mm 导出 → Zw 别名 → 锚点扫描（Win11 24H2+ 导出移除）
- 系统调用预检（Syscall）：syscall# 提取 + hook 检测
- 伪附加（PseudoDbg）：模拟调试器附加行为

### 7. 架构分层

```
demo → services → core → platform（单向依赖）
```

VMEXIT handler 注册表 + 生命周期事件广播，加功能不动核心。
服务注册表按序 Init/Teardown（虚拟化前 / 虚拟化后两阶段）。

## 二、关键踩坑（血泪汇总）

| 坑 | 教训 |
|----|------|
| MmGetVirtualForPhysical 失效帧不返回 NULL | 物理访问一律 MmCopyMemory，禁用 MmGetVirtualForPhysical |
| 日志 IRQL≥DISPATCH 读分页 PEB 蓝屏 | 日志 IRQL≥DISPATCH 直接 return；VMMCALL 只入队 PASSIVE 干活 |
| KeInvalidateRangeAllCaches 持锁发 IPI 死锁 | 必须在释放 g_BpListLock 后调用 |
| bp->Active 必须在 RebuildCc 之前置位 | 否则 0xCC 永远打不进，断点静默失效 |
| PsSetCreateProcessNotifyRoutineEx 0xc0000022 | 测试签名过不了 → 用 legacy PsSetCreateProcessNotifyRoutine |
| SSDT syscall# 提取 *(ldr+0x10) | 应传 ldr+0x10 节点地址本身 |
| 跨核影子页缓存不一致 | KeInvalidateRangeAllCaches + TLB_FLUSH_ASID（与 KVM 一致） |
| ml64 不支持 0x 前缀 | x64.asm 立即数改 h 后缀（228h） |
| 新 WDK 移除 IoRegisterPowerSettingCallback | 改用 \Callback\PowerState + ExCreateCallback |
| NPT 物理越界 = guest 蓝屏 | 固定 512GB 恒等映射（判据按 max(Base+Size)，暂不修） |
